`/reseed` guides a context-window reduction when work is mid-flight: it weighs the three ways to shrink the window — `/compact`, seed + `/clear`, or seed + `/compact` — and recommends one based on how full the window is, how deep the in-flight work is, and how much state already lives on disk. For the seed options it authors the seed (pointers to durable artifacts + volatile working-state only, never duplicating what's on disk) and hands you the exact follow-up. See `docs/skill-reference.md` for details.

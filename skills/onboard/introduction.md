`/onboard` brings a fresh agent up to speed in a repository, as a new session's first prompt. It runs `/engage`, picks an identity with `/name`, hands off to `/reseed revive` when a fresh seed is waiting, and otherwise reads the project the bounded way: a background code explorer, the README and the most recently changed documents, and every open issue title. If `CLAUDE.md` or `.claude-project.md` is stale it refreshes them on a chore branch through the normal gates, and then it holds so you can tag up before any other work. For the same session after a compaction, `/engage` alone is enough.

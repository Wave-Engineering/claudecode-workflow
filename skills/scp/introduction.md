`/scp` stages, commits and pushes your own working branch. It's free: no `/precheck` and no approval needed, so you can back up work, test in another sandbox, or pair on one branch. The only gates are the commit and push hooks, which scan for secrets and refuse protected branches. It writes a well-formatted commit message and refuses to commit on a protected branch. It does not open a PR/MR; `/scpmr` does that and runs `/precheck`. For the full workflow walkthrough, run `/ccwork tour workflow`.

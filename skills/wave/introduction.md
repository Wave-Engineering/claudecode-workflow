`/wave` is a thin routing skill that wraps the `sdlc-server` MCP's `wave_show` tool so you can check wave-pattern status from any conversation without remembering the MCP tool name. Run `/wave` (or `/wave status`) and the skill returns the server's status block verbatim — Project, Phase, Wave, Flight, current Action, Progress, and any Deferrals — letting you see at a glance where the active wave campaign is parked. The skill does not interpret or summarize the output; it is a pass-through. Future subcommands (`/wave health`, `/wave topology`, `/wave next`) are documented in `SKILL.md` but not yet wired — they will land in follow-up issues.
